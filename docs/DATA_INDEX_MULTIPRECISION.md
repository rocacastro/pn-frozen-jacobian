# Multiprecision data index

## Family dataset

- `data/multiprecision/families/protocol_frozen.json`: fixed protocol.
- `data/multiprecision/families/combined_summary.csv`: group summaries.
- `data/multiprecision/families/completed/`: completion markers for the eight groups.
- `data/multiprecision/families/sessions/`: recorded session environments.
- `data/multiprecision/families/audit/observations.csv`: 496 timed observations.
- `data/multiprecision/families/audit/precision_controls.csv`: 16 higher-precision controls.
- `data/multiprecision/families/audit/stored_trace_summary.csv`: saved-path summary.

## External-comparator dataset

- `data/multiprecision/external/current/protocol_frozen.json`: fixed adaptive protocol.
- `data/multiprecision/external/current/combined_final_summary.csv`: final group summaries.
- `data/multiprecision/external/current/extension_decisions.csv`: predeclared rule outcomes.
- `data/multiprecision/external/audit/raw_observations.csv`: 736 timed observations.
- `data/multiprecision/external/audit/precision_checks.csv`: 48 higher-precision controls.
- `data/multiprecision/external/audit/platform_sessions.csv`: platform/session metadata.
- `data/multiprecision/external/audit/external_by_phase.csv`: initial and extension phases retained separately.
- `data/multiprecision/external/platform_sensitivity/intel_followups/`: separate Intel follow-ups, excluded from the final aggregates.
